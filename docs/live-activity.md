# Иконка и Live Activity

Категория B: требуется новая нативная сборка и установка IPA. Минимальная версия этой сборки — iOS 17. В браузере и Expo Go Live Activity не отображается.

Иконка `frontend/assets/brand/app-icon.png` — 1024×1024, исходный знак окрашен в изумрудный цвет, непрозрачный тёмный фон с мягким свечением. Исходный логотип не изменён. Для повторного экспорта: `node scripts/generate-app-icon.cjs` из frontend.

## Поведение

После входа и загрузки локальных данных приложение создаёт одну Live Activity текущего профиля. Слева — системный таймер от начала текущего состояния; справа — две кнопки:

| Состояние  | Первая кнопка | Вторая кнопка | Фон                                 |
| ---------- | ------------- | ------------- | ----------------------------------- |
| Фокус      | Нет данных    | Отдых         | Изумрудный, пламя                   |
| Отдых      | Нет данных    | Фокус         | Ночной, облака и луна               |
| Нет данных | Отдых         | Фокус         | Тёмный, приглушённый знак остановки |

Поддержаны экран блокировки и компактный, минимальный, развёрнутый Dynamic Island. Нажатие вне кнопок открывает приложение. При выходе из профиля активность завершается. Таймер обновляется средствами iOS без ежесекундного запуска JavaScript.

Кнопки используют LiveActivityIntent в процессе основного приложения, записывая переход в существующий `Documents/SQLite/egofocus.db`. Отдельной базы и App Groups нет; APNs и push-entitlements не используются. История остаётся непрерывной, «Нет данных» — обычное состояние, прежние интервалы не удаляются. Транзакция блокирует конкурентную запись; смена профиля и старые кнопки проверяются по идентификатору текущей сессии. База синхронизации сохраняется для последующего слияния с сервером.

Без сети кнопки сохраняют изменения локально. Синхронизация с API выполняется при работе/возобновлении приложения; отдельной фоновой сетевой синхронизации здесь нет. iOS сама ограничивает продолжительность Live Activity и может её завершить; это не останавливает учёт времени в базе. Бесплатная подпись и работа расширения на конкретном iPhone требуют проверки после установки; расширение нельзя удалять из IPA при переподписи.

## Проверка

- Локально: `npm run typecheck`, `npm run lint`, `npm test`, `npx expo export --platform ios`.
- Тест плагина строит расширение на шаблоне Xcode из установленного Expo, проверяет зависимость сборки, встраивание `.appex`, регистрацию App Intents и отсутствие дубликатов при повторном запуске.
- GitHub Actions перед сборкой компилирует и запускает `LiveActivityHistoryTests.swift`. Проверяются переходы всех состояний, неизменность серверной базы/другого профиля, повторные нажатия, отсутствие авторизации и некорректное время. Упаковка IPA проверяет наличие `PlugIns/EgoLiveActivity.appex`.
- На Windows Swift/ActivityKit и запуск на iPhone не проверяются. Полная компиляция — в ручной сборке iPhone IPA на macOS.

На устройстве после установки новой IPA: войти, свернуть приложение, проверить обе кнопки во всех состояниях; повторить без сети, открыть приложение и сверить историю. Проверить переключение из приложения, выход из профиля, редактирование последнего интервала и Dynamic Island. В настройках iOS для EgoFocus должны быть разрешены Live Activities. При подписи Sideloadly сохранить расширение.

Документация Apple: [LiveActivityIntent](https://developer.apple.com/documentation/appintents/liveactivityintent), [ActivityKit](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities), [AppIntentsPackage](https://developer.apple.com/documentation/appintents/appintentspackage).
