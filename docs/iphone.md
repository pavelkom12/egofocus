# Установка на iPhone с Windows

## Статус

Настроен ручной GitHub Actions workflow. Реальная компиляция на macOS и установка на iPhone ещё не проверены. До получения IPA успешная проверка JavaScript не означает готовность нативной сборки.

## Сборка

1. Подключить GitHub-репозиторий и загрузить проект вместе с .github/workflows/ios-ipa.yml.
2. В репозитории открыть Actions → iPhone IPA → Run workflow.
3. Для первого использования выбрать Release. Он включает JS и работает без Metro.
4. После успешного выполнения скачать артефакт EgoFocus-Release-unsigned и распаковать ZIP: внутри IPA.
5. При ошибке сохранить iphone-build-logs для анализа.

Сборка запускается только вручную на стандартном macos-26. У приватных репозиториев есть бесплатная квота Actions; перед запуском проверить доступный остаток и не включать платный перерасход. Платные larger runners не используются.
Apple ID и сертификаты в GitHub не нужны. Неподписанный IPA не устанавливается сам по себе.

## Установка

Официальный Sideloadly: https://sideloadly.io/
Программа установлена в C:\Users\user\AppData\Local\Sideloadly\sideloadly.exe.
Сайт разработчика требует настольные iTunes и iCloud, а не версии из Microsoft Store. Существующие программы Apple пока не удалялись.

1. Подключить iPhone кабелем, разблокировать, подтвердить доверие компьютеру.
2. Открыть Sideloadly, выбрать устройство и IPA.
3. Ввести свой Apple ID непосредственно в Sideloadly; пароль и коды не отправлять в чат.
4. Подписать и установить. Не включать удаление расширений.
5. При запросе включить Developer Mode: Настройки → Конфиденциальность и безопасность → Режим разработчика, перезагрузка и подтверждение.
6. При запросе доверия профилю: Настройки → Основные → VPN и управление устройством → профиль разработчика.
7. Запустить приложение и войти в серверный профиль. Для сборки задайте GitHub Actions variable EXPO_PUBLIC_API_URL — доступный с iPhone HTTPS-адрес API с окончанием /v1. После изменения адреса нужна новая сборка Release.

С бесплатной подписью требуется обновление примерно каждые 7 дней. Сохранять один Apple ID и стабильный идентификатор приложения. Не удалять приложение для обновления — это может удалить базу данных. Сохранность при повторной подписи необходимо проверить на тестовом профиле.

## Быстрая разработка

Собрать Debug тем же workflow и установить через Sideloadly.
На Windows:

```powershell
Set-Location 'F:\Development\EgoFocus\frontend'
npm.cmd start -- --lan
```

Компьютер и телефон должны находиться в одной локальной сети. Разрешить Node.js в брандмауэре для частной сети. Открыть dev client на iPhone и выбрать Metro URL.
Debug и Release имеют один Bundle ID, поэтому заменяют друг друга.
Если Debug не запускается с бесплатной подписью, анализировать лог, не считать маршрут проверенным.

## Данные и проверка

IndexedDB браузера не переносится автоматически в SQLite iPhone. Серверная синхронизация и экспорт/импорт пока не реализованы.
Проверить регистрацию, смену состояния, закрытие и повторный запуск, офлайн-работу, смену пароля, статистику, системный Liquid Glass и обновление IPA поверх существующего.
Live Activities в текущем приложении ещё не реализованы; установленные пакеты не означают наличия расширения.
