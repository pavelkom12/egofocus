# EgoFocus

Приложение на React Native / Expo SDK 58 и отдельный HTTP API с PostgreSQL. Только тёмная тема, изумрудные акценты, интерфейс на русском.

## Структура и запуск

- `frontend/` — приложение для iPhone и браузера. Зависимости устанавливаются командой `npm.cmd ci --prefix frontend`.
- `backend/` — API на Node.js и Fastify, миграции PostgreSQL и интеграционные тесты.
- `compose.yaml` — API и PostgreSQL в отдельных контейнерах с постоянным томом для базы данных.

Из корня можно запускать клиент привычной командой `npm.cmd run web`. Для сервера подготовьте локальный `.env` по образцу `.env.example` и выполните `docker compose up -d --build --wait`. Порядок запуска с чистого клона, контракт API и пример запроса описаны в [инструкции сервера](backend/README.md).

## Открыть в браузере

В PowerShell:

```powershell
Set-Location 'F:\Development\EgoFocus\frontend'
npm.cmd run web
```

Откройте адрес, который напечатает Expo (обычно http://localhost:8081).
Первый запуск: нажмите «Нет профиля? Зарегистрироваться», укажите имя, дату рождения в формате ДД.ММ.ГГГГ и пароль (минимум 8 символов).

Браузерная версия хранит данные в IndexedDB. Используйте один и тот же браузер и адрес: localhost и 127.0.0.1 — разные хранилища. При очистке данных сайта локальные профили и история удаляются.

## Реализовано

- Локальная регистрация, вход, сохранение сеанса и выход. Отдельная история каждого профиля.
- Солёный PBKDF2-HMAC-SHA256 (600 000 итераций) вместо открытых паролей.
- Непрерывная история от даты рождения: «Нет данных», «Фокус», «Отдых».
- Таймер по сохранённому времени начала; восстановление после перезапуска и возвращения из фона.
- Смена фокуса/отдыха с сохранением до обновления интерфейса и защитой от повторного нажатия.
- История завершённых состояний: подгрузка по 20 записей, разделители дней, подсказки интервалов.
- Статистика за сегодня, текущую неделю с понедельника и всё время с рождения.
- Доля фокуса считается от всего времени выбранного периода, включая «Нет данных».
- График последних 7 дней имеет собственный явно указанный период.
- Профиль: имя, почта, пароль, выбор главного показателя статистики.
- Плавающая панель трёх вкладок: GlassView на поддерживаемых iPhone, полупрозрачный blur в браузере.
- На iPhone данные хранятся в SQLite; в браузере — в IndexedDB.

## Границы текущего прототипа

Вход пока локальный и доступен офлайн. Это не серверная авторизация и не защита от владельца устройства, имеющего доступ к его хранилищу. В будущем регистрация и новый вход будут требовать интернет, а уже открытый сеанс сможет работать офлайн.

Почта пока не подтверждается и не используется для восстановления пароля. Дата рождения после регистрации не редактируется, чтобы случайно не изменить границы истории. Редактирование и удаление доступны через общий редактор временной шкалы.

Клиент пока работает со своим локальным хранилищем. Серверный API готов для подключения; обмен данными клиента с ним и автоматическое слияние истории требуют отдельной интеграции. Браузерный локальный сервер нужен для открытия страницы; после загрузки работа с данными не требует интернета. Автономный повторный запуск браузерной версии без локального сервера (PWA) пока не реализован.

Нативный Liquid Glass и SQLite требуют отдельной проверки на iPhone. Браузер не воспроизводит системный Liquid Glass. Проверена веб-сборка и статические проверки; интерактивные проверки в браузере пользователь выполняет самостоятельно.

## Структура

- frontend/src/domain.ts — непрерывная шкала времени, расчёты и валидация.
- frontend/src/repository.ts — локальный интерфейс авторизации и изменения профиля/истории.
- frontend/src/storage.ts — транзакционное SQLite-хранилище iPhone.
- frontend/src/storage.web.ts — атомарные транзакции IndexedDB.
- frontend/src/screens.tsx — основные экраны.
- frontend/src/ui.tsx — общие компоненты, тёмная тема и стеклянная панель.
- docs/architecture.md — границы будущей серверной части.

## Демоданные

На странице входа нажмите «Попробовать с демоданными» или в профиле — «Создать демопрофиль». Создаётся отдельный профиль demo (если занят — demo2 и далее), пароль demo12345. В нём более 200 переходов за последние 28 дней, включая неизвестные периоды и отдых через полночь. Данные генерируются относительно момента нажатия и сохраняются в локальной БД. Существующие профили не изменяются; каждое нажатие создаёт новый демопрофиль. Пароль публичный, профиль предназначен только для проверки.

## Редактор истории

Нажмите карандаш или корзину у записи. Корзина сразу готовит замену на «Нет данных» в черновике — база изменится только после «Сохранить».

- Горизонтальная шкала открывается на выбранном интервале; страницы подгружаются автоматически при прокрутке. Масштаб: 1, 6 или 24 часа.
- Нажмите участок для выбора. Перетаскивайте светлые ползунки начала и конца. При сужении освободившееся время становится «Нет данных», при расширении выбранное состояние заменяет пересечённые участки.
- Удержание ползунка или участка открывает меню состояний и удаления. Кнопка «Действия» открывает то же меню.
- Полоса «До изменений» показывает исходные состояния изменённых участков, пока открыт редактор.
- Для точных границ доступны поля ДД.ММ.ГГГГ ЧЧ:ММ:СС и «Применить границы». «К началу» и «К концу» перемещают шкалу.
- «Отменить» сбрасывает весь черновик и оставляет окно открытым. Крестик закрывает без сохранения. «Сохранить» атомарно записывает изменения и закрывает окно.
- Изменяется только время до момента открытия редактора. Если профиль изменился в другом окне, сохранение отклоняется — нужно закрыть и открыть редактор заново.

Проверены 28 тестов модели, TypeScript, ESLint и веб-сборка. Жесты в браузере и на iPhone ещё не проверены пользователем.
